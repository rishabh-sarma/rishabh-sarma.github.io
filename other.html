Misc

Maple

I frequently use Maple, more specifically the q-series and subsidiary packages developed by Frank Garvan, to perform computations involving partitions, q-series and modular forms. Below is a collection of related files where I search and find identities for partition and overpartition-theoretic objects and statistics using automorphic-algorithmic techniques in Maple. I have also prepared an installation guide for these packages that are available for download at Frank Garvan's research webpage. I update this page with new files and codes as I go.


Frank Garvan's QSERIES package : This link directs to Frank Garvan's webpage containing his QSERIES and other related packages such as RANK, CRANK, ETA and THETAIDS for installation and use. Each package comes with a tutorial.

QSERIES package installation guide : This pdf serves as a guide to install the QSERIES and other packages. Of course, one needs to have a Maple license bought and installed first.

Partition rank identities : This link directs to a GitHub repository containing Maple files with codes for finding and proving partition rank identities modulo higher primes that express elements of the p-dissections of the two variable partition rank generating function (variable z being replaced by the primitive p-th root of unity) in terms of quotients of generalized eta products with cyclotomic coefficients. These appear in my paper "New symmetries for Dyson’s rank function (with Frank Garvan), Ramanujan J. 65 (2024), 1883–1939". The code implements an algorithm described in the paper.

Partition crank identities : This link directs to a GitHub repository containing Maple files with codes for finding and proving partition crank identities modulo higher primes that express elements of the p-dissections of the two variable partition crank generating function (variable z being replaced by the primitive p-th root of unity) in terms of quotients of generalized eta products with cyclotomic coefficients. These appear in my paper "Transformation and symmetries for the Andrews–Garvan crank function , Hardy–Ramanujan J. 47 (2024), 1–25". The code implements an algorithm described in the rank symmetry paper cited earlier.

Overpartition rank and crank identities : This link directs to a GitHub repository containing Maple files with codes for finding and proving overpartition rank and crank identities modulo higher primes that express elements of the p-dissections of the two variable overpartition rank and crank generating functions (variable z being replaced by the primitive p-th root of unity) in terms of quotients of generalized eta products with cyclotomic coefficients. These appear in my paper "Symmetries for overpartition rank and crank functions (with Frank Garvan)". The code implements an algorithm described in the paper.
